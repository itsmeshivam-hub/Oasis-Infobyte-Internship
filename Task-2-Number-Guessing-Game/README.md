# Task 2 – Number Guessing Game

## Description
A Java-based Number Guessing Game in which the computer generates a random number and the player attempts to guess it within a limited number of attempts.

## Features
- Random number generation.
- Too High and Too Low hints.
- Attempt counter.
- Limited attempts per round.
- Multiple difficulty levels: Easy, Medium, and Hard.
- Play Again option.
- Score tracking across multiple rounds.

## Technologies Used
- Java
- Random Class
- Scanner
- Loops and Conditional Statements

## How to Run
1. Open the project in IntelliJ IDEA.
2. Run the main Java file.
3. Select a difficulty level.
4. Enter your guesses and enjoy the game.
