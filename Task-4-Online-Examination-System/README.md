# Task 4 – Online Examination System

## Description
A Java Swing-based Online Examination System that allows students to log in, update their profiles, attend multiple-choice examinations, and view their results.

## Features
- Student login authentication.
- Profile update functionality.
- MCQ-based examination interface.
- Four options for each question.
- Next and Previous question navigation.
- Countdown timer.
- Automatic submission when time expires.
- Manual submission with confirmation.
- Result screen showing score and performance.
- Logout functionality.

## Technologies Used
- Java
- Java Swing
- Java AWT
- Object-Oriented Programming (OOP)
- IntelliJ IDEA

## How to Run
1. Open the project in IntelliJ IDEA.
2. Open the main Java file.
3. Run the application.
4. Log in using the configured credentials.
5. Update your profile and start the examination.
