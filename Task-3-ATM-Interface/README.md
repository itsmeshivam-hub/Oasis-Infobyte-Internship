# ATM Interface – Java

## About the Project
The ATM Interface is a console-based Java application developed as **Task 3** of my Java Developer Internship at **Oasis Infobyte**.

This project simulates basic ATM operations using Object-Oriented Programming (OOP) concepts and Java collections.

## Features
- User ID and PIN Authentication
- Maximum 3 Login Attempts
- Check Account Balance
- Cash Withdrawal
- Cash Deposit
- Money Transfer Between Accounts
- Transaction History
- Insufficient Balance Validation
- Account Balance Updates

## Technologies Used
- Java
- Object-Oriented Programming (OOP)
- ArrayList
- HashMap
- Exception Handling
- IntelliJ IDEA

## Project Structure
- `Main.java` – Application entry point
- `ATM.java` – ATM menu and operations
- `Account.java` – Account details and balance management
- `Bank.java` – Account storage and management
- `Transaction.java` – Transaction records

## How to Run
1. Clone or download this repository.
2. Open the project in IntelliJ IDEA.
3. Ensure all Java files are inside the same source folder and package.
4. Run `Main.java`.

## Learning Outcomes
- Practical implementation of OOP concepts
- Working with Java collections
- Implementing authentication and validation
- Managing transactions using Java
